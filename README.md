# 📊 Japanese Venture Capital Firms Analysis

![Project Cover](cover.png)

---

## 🚀 Project Overview
This project performs an in-depth **Exploratory Data Analysis (EDA)** on venture capital firms in Japan to uncover trends, patterns, and investment insights.

The goal is to transform raw data into **actionable insights** that reflect market behavior, investment distribution, and growth trajectories in the Japanese VC ecosystem.

---

## 🎯 Objectives
- Analyze the distribution of venture capital firms in Japan
- Identify investment trends and growth patterns
- Perform data cleaning and preprocessing
- Generate meaningful visualizations
- Extract business-level insights from data

---

## 📂 Dataset Information
- **Dataset Name:** Japanese VC Firms Dataset  
- **Format:** CSV  
- **File:** `japanese_vcfirms_dataset.csv`

### Key Features:
- Firm names
- Investment data
- Categories / sectors
- Regional or operational attributes

## ▶️ How to Run the Project

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/Japanese-VentureCapital-Firms-Analysis.git
cd Japanese-VentureCapital-Firms-Analysis
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run Notebook
```bash
jupyter notebook
```

Open:
```
Japanese_VCFirms_Data_Analysis.ipynb
```
